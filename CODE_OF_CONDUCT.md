# Código de conducta

Misiva adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
como código de conducta.

En resumen: queremos una comunidad abierta, acogedora y libre de acoso para todas las personas,
sin importar su edad, cuerpo, discapacidad, etnia, identidad o expresión de género, nivel de
experiencia, educación, nivel socioeconómico, nacionalidad, apariencia, religión u orientación sexual.

- Sea respetuoso con opiniones y experiencias distintas.
- Dé y reciba retroalimentación constructiva con amabilidad.
- No se toleran el acoso, los insultos, los ataques personales ni la publicación de datos privados ajenos.

Para reportar un comportamiento inaceptable, contacte de forma privada a las personas que mantienen el
proyecto (ver la sección «Contacto» del repositorio). Todos los reportes se revisarán con confidencialidad.

# Política de seguridad

## Versiones con soporte

Solo la última versión publicada recibe correcciones de seguridad.

## Reportar una vulnerabilidad

**No abra un *issue* público.** Use el reporte privado de GitHub
(pestaña *Security* → *Report a vulnerability*) e incluya:

- Descripción del problema y su impacto.
- Pasos para reproducirlo (versión, sistema operativo, web o escritorio).
- Si la tiene, una propuesta de corrección.

Intentaremos responder en un plazo de 7 días.

## Alcance

Misiva está pensada para uso local o en una red de confianza: **no incluye autenticación**. Si la
publica en internet, protéjala detrás de un proxy con inicio de sesión o una VPN, ya que cualquiera
con acceso podría subir o borrar imágenes en `/api/upload`.
